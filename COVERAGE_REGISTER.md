# Atlas Coverage Register v0.1

**Status:** provisional editorial inventory, not a completed technical or scientific audit.

## Dimensions to track independently

1. **Concept coverage** — subject exists as a knowledge node.
2. **Evidence provenance** — primary sources, dates, attribution, uncertainties.
3. **Model fidelity** — units, assumptions, calibration and limitations.
4. **Implementation maturity** — concept, repository identified, prototype, tested, deployed.
5. **Integration maturity** — linked from canvas, deep-linked to functioning view, data interoperable.
6. **Knowledge gaps** — explicit missing observations, concepts, data or tools.

An identified repo is not a tested deployment. A live page is not a validated simulation. A diagram is not evidence for every assertion shown on it.

## Verification protocol

Every status change should include an evidence reference, reviewer, date, verification method and result. Do not infer progress from the number of links. Never mark a node scientifically verified merely because its web page loads.

## Publishing and licensing

Concept nodes and independently written descriptions can be published without embedding third-party diagram files. Original diagrams remain a private reference inventory until their respective reuse rights and attribution are established.
